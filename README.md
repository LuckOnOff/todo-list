## Описание проекта

`Todo-List` — это приложение, где пользователи могут:
- Добавлять задачи.
- Помечать выполненные задачи.
- Редактировать существующие задачи.
- Удалять задачи.
- Визуализировать задачи с удобным пользовательским интерфейсом.
- Менять тему приложения на светлую (по умолчанию) и темную.

Приложение создавалось для демонстрации работы с React и TypeScript, а также смены тем и кастомных стилей через `styled-components`.

## Установка

Перед началом работы убедитесь, что на вашем устройстве установлены [Node.js](https://nodejs.org/) и [npm](https://www.npmjs.com/) или [yarn](https://yarnpkg.com/).

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/LuckOnOff/todo-list.git
   ```

2. Перейдите в папку проекта:
    ```bash
    cd todo-list
    ```

3. Установка зависимостей
    ```bash
    npm install
    # или
    yarn install
    ```

---

## Запуск

1. В режиме разработки:
    ```bash
    npm start
    # или
    yarn start
    ```

Приложение откроется в браузере по адресу http://localhost:3000

2. Сборка для продакшена:
    ```bash
    npm run build
    # или
    yarn build
    ```

Результат сборки будет находиться в папке /build.
